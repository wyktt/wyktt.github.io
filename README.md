## 📖 关于

这是作者 **wyktt** 的个人博客，记录生活、技术与想法。

- **主题**: Hexo Theme Redefine v2.9.0
- **作者**: wyktt
- **描述**: A new start.

## 🎨 主题特性

- 响应式设计，支持桌面和移动端
- 深色/浅色模式切换
- 文章目录导航
- 代码高亮（支持 GitHub / VS2015 主题）
- 字数统计与阅读时间估算
- 友情链接、标签云、分类归档
- 社交链接集成（GitHub、Twitter、Telegram、知乎、Bilibili 等）
- 首页轮播副标题
- 图片懒加载
- 页脚运行时间统计

## 🚀 本地运行

```bash
# 安装依赖
npm install

# 启动本地服务器
hexo server

# 访问 http://localhost:4000
```

## 📦 构建部署

```bash
# 清理缓存
hexo clean

# 生成静态文件
hexo generate

# 部署到远程仓库
hexo deploy
```

## 📁 目录结构

```
├── 2026/                 # 按年份组织的文章

├── fonts/                # 字体文件
├── gallery/              # 图库
├── images/               # 图片资源
├── js/                   # JavaScript 脚本
├── tags/                 # 标签页面
└── index.html            # 首页
```
